# dsh-session-sweeper · DSH 会话清道夫

给 DeepSeek Harness 补上缺失的「删除对话」——而且是批量版。

DSH 官方只有归档：会话从列表消失，日志文件永远留在 `~/.dsh/sessions` 里越攒越多。
现有同类插件多是「单条删除 + 插件自建回收站」。这个插件的差异化：

- **占用排行**：设置页「会话清理」按磁盘大小从大到小列出全部会话（标题、token 数、最后活跃时间）
- **批量清理**：规则一键选中（30 天未活跃 / 大于 5 MB / 已归档）或手动勾选，成批处理
- **进 Mac 系统废纸篓**：删除 = 移进 macOS 废纸篓（Finder 方式，可「放回原处」），
  不自建回收站、插件永不执行永久删除；清空废纸篓前随时能找回
- **确认即删、无状态拦截**（v0.1.2，用户拍板）：单条删除在侧边栏会话「…」菜单里，
  带确认弹窗；批量走两段式确认。只要用户确认，任何状态的会话（包括正在进行中、
  当前会话）都可移入废纸篓——「进行中」只在排行里作信息展示，不再拦截或自动跳过
- **删完即消失**（v0.1.3）：文件移入废纸篓后同步释放工作区注册表账目
  （detach / unarchive / unpin，进行中会话先停回合），侧边栏行立即消失、无需重启；
  注册表不可用时自动降级为旧行为（重启后自洽），释放失败不回滚文件、记入审计并在界面提示
- **审计留痕**：每次操作记入 `~/.dsh/sweeper/audit.jsonl`（不含会话内容）

清理范围：会话日志目录 + 对应投影缓存。共享附件库（内容寻址、多会话共用）永不触碰。

## 安装（概要）

1. 把本目录放到 Mac 上，如 `~/dsh-plugins/dsh-session-sweeper`（不要放进 `~/.dsh/sessions`）
2. 先确认 profile 名：`ls ~/.dsh/profiles`
3. 用插件管理器添加本地目录，或在对应 profile 里以 `link:` 方式挂上本包并加入
   `dsh.profile.bundles`，重启 DSH
4. 打开设置页看「会话清理」一节；或访问 `/.dsh-session-sweeper/health` 应返回 `{"ok":true}`

详细步骤与验活清单见 INSTALL-MAC.md。方案定版见 SPEC.md。

## 安全说明

- 插件以 DSH 进程权限运行，只读写 `~/.dsh` 与系统废纸篓，不发网络请求
- 所有待删路径都做包含性校验（必须位于 sessions 根目录内），session id 只允许单个安全路径段
- 移废纸篓失败时不改动任何账目，可安全重试
